# База данных «Спортивный клуб»

## Таблицы
- **members** — участники клуба (id, имя, email, возраст).
- **trainers** — тренеры (id, имя, специализация).
- **classes** — занятия (id, название, тренер, вместимость).
- **visits** — посещения (кто и когда пришел).
- **payments** — оплаты (кто, сколько и за какой абонемент).

## Ограничения и проверки
- `NOT NULL` — имя, email, дата.
- `UNIQUE` — email участника.
- **CHECK** — возраст >= 14, вместимость > 0.
- Индексы: `idx_visits_member`, `idx_classes_trainer`.

## Проверочные запросы
В файле `checks.sql` 9 запросов: активные абонементы, загруженность по датам, тренеры и их классы, «спящие» клиенты, топ-3 занятий, выручка по абонементам и др.

## Как запустить
1. Создайте пустую БД SQLite `sports.db`.
2. Выполните `schema.sql` (создание таблиц).
3. Выполните `seed.sql` (добавление данных).
4. Выполните `checks.sql` (проверка запросов).
