# База данных «Спортивный клуб»

## Таблицы
- **members** — участники клуба (id, имя, email, возраст).
- **trainers** — тренеры (id, имя, специализация).
- **classes** — занятия (id, название, тренер, вместимость).
- **schedule** — расписание занятий (день недели, время начала и окончания, зал).
- **visits** — посещения (кто, когда и на какое занятие пришел).
- **payments** — оплаты (кто, сколько и за какой абонемент).

## Ограничения и проверки
- `NOT NULL` — имя, email, дата.
- `UNIQUE` — email участника.
- `CHECK` — возраст >= 14, вместимость > 0.
- Индексы: `idx_visits_member`, `idx_classes_trainer`.
- Внешние ключи (Foreign Keys) связывают все таблицы между собой.
- Поле `end_date` в таблице `payments` хранит дату окончания абонемента, что позволяет корректно проверять его срок действия.

## Проверочные запросы
В файле `checks.sql` 10 запросов: активные абонементы (с проверкой по `end_date`), загруженность по датам, тренеры и их классы, «спящие» клиенты, топ-3 занятий, выручка по абонементам, конфликты в расписании (пересечение занятий у одного участника) и др.

## Как запустить
1. Создайте пустую БД SQLite `sports.db`.
2. Выполните `schema.sql` (создание таблиц, включая расписание).
3. Выполните `seed.sql` (добавление данных и расписания).
4. Выполните `checks.sql` (проверка запросов).
